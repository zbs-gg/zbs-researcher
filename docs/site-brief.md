# ZBS Researcher — бриф для сайта (hand-off)

> **Сайт здесь не строим.** Это бриф для внешней работы: отдаётся дизайнеру /
> верстальщику / отдельной сессии. В этом репо живёт продукт (плагин,
> инсталлер, доки) — не лендинг. Всё, что нужно для сайта, собрано ниже:
> позиционирование, структура, готовые копи-блоки RU+EN, список ассетов.

---

## 1. Позиционирование

**Одной строкой (внутренняя, для команды):** заебись-ресёрчер — глубокий
multi-source ресёрч с реакциями живых людей за минуты и $0, пока из этого
строят целые компании.

Развёрнуто:

- Это не «ещё один AI-саммарайзер выдачи». Раннер тянет **параллельно до 17
  каналов**: LLM-линзы (Gemini/Grok/Perplexity) + прямые коннекторы с цифрами,
  которые LLM не выдумает — HN points, Polymarket odds, GitHub stars,
  hiring-сигнал, реальные посты Reddit/Bluesky/Threads с реакциями живых людей.
- **План перед запуском.** Каждый прогон начинается с research-plan.md — что
  ищем, где, какие противоречия ждём. Не «холодный keyword blast».
- **$0 по умолчанию.** Дефолтный запуск не бьёт ни в Anthropic, ни в OpenAI
  API. Бесплатные каналы работают вообще без ключей. Апгрейды — по одному,
  честно, с ценой.
- **Контраст, на котором стоит вся подача:** из «дать людям ресёрч с
  реакциями реальных пользователей» компании строят целые стартапы с
  подписками. Здесь это — одна команда в терминале и минуты до отчёта.
- Персона: **ZBS Researcher** («Заебись-Ресёрчер») — названный ресёрчер,
  который представляется, задаёт два вопроса и настраивается под тебя
  (род обращения + тон). Бренд живёт в копи; технический id плагина —
  `deep-research`, это на сайте не выпячивать.

**Чем НЕ является (не обещать на сайте):** не SaaS, не веб-аппка, не
«агентство под ключ». Это плагин для Claude Code: нужен установленный
`claude` CLI. Node — только для npx-однострочника (есть native fallback без
node).

## 2. Аудитория

1. **Клиенты Ника** — операторы бизнесов и продуктов, которым нужен ресёрч
   «что реально говорят люди / что реально продаётся», а не маркетинговые
   саммари. Смотрят демо-видео, решают за 2 минуты.
2. **CIS-ниши** — русскоязычные фаундеры, продакты, инфопродуктовые ребята,
   Telegram-first аудитория. Отсюда RU-копия — первична, EN — параллельна,
   не переводом «по остаточному принципу».
3. **Lite-technical операторы** — терминал не пугает, но никто не будет
   собирать окружение по README на 400 строк. Отсюда обязательный npx-путь
   в один шаг и блок «нет node?» с двумя честными альтернативами.

Общее у всех трёх: платить подписку за «ещё один ресёрч-тул» не хотят,
цифра «$0 по умолчанию» — главный крючок после самого демо.

## 3. Структура лендинга

Одностраничник, тёмная тема (терминальная эстетика — сам продукт живёт в
терминале, сайт должен это продолжать, а не «облагораживать»).

1. **Hero.** Banner-арт ZBS RESEARCHER + заголовок + подзаголовок + CTA
   `npx -y zbs-researcher@latest` (копируемая строка) + **терминал-демо GIF**
   (живой прогон с анимированным бордом коннекторов — главный визуал
   страницы, он продаёт больше любого текста).
2. **«Как это работает» — 3 шага.**
   1. `npx -y zbs-researcher@latest` — инсталлер сам находит `claude`,
      добавляет marketplace, ставит плагин.
   2. Открываешь Claude Code, говоришь «запусти deep research» — персона
      здоровается, задаёт пару вопросов, гонит бесплатный прогон.
   3. Через минуты — отчёт: план, сырые данные по каналам, синтез
      противоречий, шарабельный `brief.html`.
3. **Tiers-таблица.** Tier 0 — $0, без ключей (HN, hiring, Polymarket,
   GitHub, Reddit, Bluesky, радары). Tier 1 — свои ключи Gemini/Grok.
   Tier 2 — один ключ OpenRouter на все LLM-линзы. Опционально —
   Telegram / TikTok-IG / Threads / Meta Ads (честно пометить: opt-in,
   у части — платный вендор). Источник правды — таблица коннекторов в README.
4. **Honest security-блок «что и куда уходит».** Коннекторы отправляют на
   публичные эндпоинты текст исследовательского запроса — и ничего больше.
   Никаких вызовов Anthropic; OpenAI — только явный opt-in. Ключи лежат
   локально в секрет-папке, в отчёты и логи не попадают. Ссылка на полный
   разбор per-connector в CONFIGURATION.md репозитория. Этот блок не прятать
   в футер — он часть позиционирования «честный инструмент».
5. **CTA-финал.** Повтор однострочника `npx -y zbs-researcher@latest` +
   native fallback (две команды `claude plugin …` без node) + ссылка на
   GitHub `zbs-gg/zbs-research`.

Опционально (если делается вторая секция): галерея скринов — brief.html,
персона-вопросы, борд.

## 6. Ограничения и рамки

- Не обещать SaaS/веб-версию, аккаунты, «облако» — этого нет.
- Технический id плагина `deep-research` на сайте не светить как бренд;
  бренд — ZBS Researcher.
- Honest-блоки (security, платные opt-in каналы) — обязательны, это часть
  продукта, а не юридическая сноска.
- Мат — нигде в публичной копии; дерзость достигается ритмом и контрастом,
  не лексикой.
- Репозиторий: `https://github.com/zbs-gg/zbs-research`. Команда установки
  без npx: `claude plugin marketplace add zbs-gg/zbs-research` +
  `claude plugin install deep-research@zbs-research`.
